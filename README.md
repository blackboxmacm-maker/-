# Blackbox Mahidol · ตารางห้องและการจองห้อง

เว็บตารางห้อง (React + Vite) เก็บข้อมูลบน Supabase ขึ้นเว็บด้วย Vercel แยกจากระบบหลังบ้านโรงเรียน

## หน้าในเว็บ
- `/` ตารางห้องรายสัปดาห์ (จันทร์–ศุกร์ เปิดเสาร์–อาทิตย์ได้ในตั้งค่า) + กล่อง "วันนี้"
- `/book` ขอใช้ห้อง: จองใหม่ / เปลี่ยนวัน-เวลาคาบ / ยกเลิกคาบ (`?mode=move` หรือ `?mode=cancel`)
- `/equipment` ขอใช้อุปกรณ์ สำหรับอาจารย์ที่มีคาบประจำ (เลือกคาบในสัปดาห์นั้น)
- `/approve` หน้ารับรองคาบ/งาน ให้แอดมินและพนักงานช่วยกันกด (ใช้ PIN แอดมิน หรือ PIN พนักงาน)
  - ใส่ `?as=teacher` `?as=student` `?as=renter` ท้ายลิงก์ เพื่อเลือกประเภทไว้ให้ก่อน
- `/staff` ตารางกะพนักงาน (ดูอย่างเดียว) — ส่งให้พนักงานดูว่าใครเข้างานเวลาไหน
- `/admin` หน้าแอดมิน (ใส่ PIN): รอรับรอง · ตาราง/ลงคาบเรียน · กะพนักงาน · ค่าโอที · ตั้งค่า

## ค่าโอที
งานมหาลัย 60 บาท/ชม. · งานภายนอก 200 บาท/ชม. (แก้ได้) · จ–ศ นับเฉพาะก่อน 09:00 และหลัง 17:00 · ส–อา นับทั้งกะ
ประเภทงานเลือกตอนลงกะ (ถ้าวันนั้นมีงานเช่า ระบบเลือก "งานภายนอก" ให้ก่อน)

## นำเข้าจาก Excel (แอดมิน → ตั้งค่า)
ไฟล์ปฏิทิน 1 ชีต = 1 เดือน · ตัวอักษรสีฟ้า = White Box, สีดำ = Black Box · ข้อความ "WB+BB" ลงทั้งสองห้อง

## ขึ้นเว็บ (ทำครั้งเดียว)
1. Supabase → SQL Editor → วางไฟล์ `supabase.sql` → Run (ถ้าเคยรันเวอร์ชันก่อนแล้ว ให้รันเฉพาะส่วน `room_shifts` ท้ายไฟล์)
   (ใช้โปรเจกต์ Supabase เดิมได้ ชื่อตาราง `room_bookings` / `room_settings` ไม่ชนกับของเดิม)
2. GitHub → สร้าง repo ใหม่ → อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
3. Vercel → Add New → Project → เลือก repo → Framework = Vite
   (ถ้าไฟล์อยู่ในโฟลเดอร์ย่อย ให้ตั้ง Root Directory เป็นชื่อโฟลเดอร์นั้น)
4. Environment Variables
   | Name | Value |
   |---|---|
   | `VITE_SUPABASE_URL` | Project URL |
   | `VITE_SUPABASE_ANON_KEY` | publishable / anon key |
   | `VITE_ADMIN_PIN` | PIN เข้าหน้าแอดมิน |
   | `VITE_STAFF_PIN` | PIN พนักงาน ใช้เข้าหน้า `/approve` เท่านั้น (ไม่เข้าหน้าแอดมิน) |
   | `LINE_CHANNEL_ACCESS_TOKEN`, `LINE_TARGET_ID` | (ไม่บังคับ) แจ้งเตือนเข้ากลุ่ม LINE เมื่อมีคำขอใหม่ ใช้ค่าเดียวกับระบบเดิมได้ |
5. Deploy → เข้า `/admin` → แท็บ ตั้งค่า → ใส่ชื่อ เบอร์ LINE ของผู้ติดต่อ ห้อง อุปกรณ์ → บันทึก

## หมายเหตุ
- ไม่ใส่ค่า Supabase แอปจะเก็บข้อมูลไว้ในเบราว์เซอร์เครื่องนั้น (ใช้ลองเล่นได้)
- เหมือนระบบเดิม: ล็อกหน้าแอดมินด้วย PIN และ anon key อ่านข้อมูลได้ (รวมเบอร์โทรผู้จอง) เหมาะกับใช้ในทีม
